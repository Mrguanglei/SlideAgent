# 智谱清言工具卡片样式分析

## 左侧对话区的工具卡片样式

### 1. 补充信息卡片
- 样式：圆角矩形按钮，白色背景，灰色边框
- 图标：绿色方形图标（带文档符号）
- 文字："补充信息" + 状态标签"已跳过"
- 右侧：下拉箭头（可展开/收起）
- 整体是一个可点击的按钮样式

### 2. 任务执行规划按钮
- 样式：**胶囊形状按钮**，浅灰色背景，圆角
- 图标：左侧有一个日历/任务图标
- 文字："任务执行规划"
- 右侧：右箭头（>）表示可点击打开面板
- **不是卡片，是独立的按钮！**

### 3. 搜索网页按钮
- 样式：**胶囊形状按钮**，浅灰色背景，圆角
- 图标：左侧有搜索图标（Q）
- 文字："搜索网页" + 搜索关键词（灰色，省略显示）
- 右侧：右箭头（>）
- 多个搜索可以有多个这样的按钮

### 4. 搜索图片按钮
- 样式：**胶囊形状按钮**，浅灰色背景，圆角
- 图标：左侧有图片图标
- 文字："搜索图片" + 搜索关键词（灰色，省略显示）
- 右侧：右箭头（>）

## 关键区别
1. 工具按钮是**独立的胶囊形状**，不是包裹在卡片里
2. 工具按钮之间有**普通文字内容**穿插（AI的解释说明）
3. 点击工具按钮会打开右侧面板显示详情
4. 按钮样式统一：浅灰背景 + 圆角 + 图标 + 文字 + 右箭头
